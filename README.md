# Remix Rooms

Kids creative remix MVP: start from stylish room templates, remix décor/layout, and share to a **friends & family gallery** (not the open internet). No open chat.

## Play locally

```bash
npm install
npm run dev
```

## What works

- Template-first start (6 rooms) — no blank canvas
- Editor tools: move, recolor, stretch, stamp props, walls/floors
- Remix lineage view
- Optional challenge ribbons (cosmetic only)
- Friends & family gallery with share confirmation metaphor
- Local persistence via `localStorage`

## Stubs / MVP limits

- Gallery friends/family entries are **simulated sample data**
- No real accounts, invites, or parent approval backend
- No open chat (intentionally omitted)
